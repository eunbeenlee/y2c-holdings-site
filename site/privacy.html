개인정보 처리 안내

공개 전 검토용 · Draft — not a finalized privacy notice

이 페이지는 현재 홈페이지의 문의 기능을 설명하는 초기 안내입니다. 실제 문의 수신 시스템이 연결되기 전에 개인정보 처리자 연락처, 보유기간, 삭제 절차, 제3자 제공 및 국외이전 여부를 확인해 확정해야 합니다.

1. 문의 정보 / Contact information

문의 양식은 회사명, 파트너 유형, 담당자명, 업무용 이메일, 국가·지역, 관심 분야 및 문의 내용을 입력받습니다. 민감정보, 주민등록번호, 금융정보, 신분증 사진은 입력하지 마세요.

2. 현재 문의 방식 / Current mode

기본 설정에서는 입력한 정보가 서버에 저장되거나 자동 전송되지 않습니다. 화면에 문의 내용을 준비하여 복사할 수 있게 합니다. 관리자가 추후 이메일 주소 또는 외부 폼을 연결한 경우 전송·보관·수탁 구조가 달라지므로 이 안내를 갱신해야 합니다.

3. 이용 목적 / Purpose

제휴 상담, 거래 적합성 검토, 사업개발 관련 연락을 목적으로만 문의를 요청합니다. 선택적 광고성 정보 수신 동의는 현재 별도 제공하지 않습니다.

4. 보유기간·제3자·국외이전 / Retention and disclosure

실제 수신 시스템을 운영하는 시점에 보유기간, 위탁사업자, 접근권한, 개인정보 주체의 권리행사 방법과 국외이전 근거 등을 명확히 기재해야 합니다.

5. English summary

This is a pre-launch draft. The default static website does not submit or store inquiry form data on a server. If an email service or external form endpoint is configured, the operator must update this notice with verified contact details, retention periods, processors, transfer arrangements and data subject rights before enabling live submissions.
