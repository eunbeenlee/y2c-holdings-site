# V20 Revision Notes

## 디자인
- 원본 육각형 로고를 헤더에 작게 유지. 새로운 파란 로고/테마 제외.
- 화이트·웜오프화이트·차콜, 작은 샴페인골드 강조선으로 통일.
- 산세리프 중심 타이포그래피, 과한 색 보정·금색 장식·그라디언트 이미지 페이드 축소.
- 회의실 사진으로 모든 카테고리를 채우는 대신 업무 자료, 제품 샘플, 창고 작업, 제품 클로즈업으로 구분.
- 폼·가격·관리자 페이지의 불필요한 사진 배너 제거. 실제 입력과 가격 비교에 집중.
- 근거 없는 고객사 로고, 파트너 수, 사업 성과 숫자는 추가하지 않음.

## 정확한 이미지 연결
- 글로벌 사업개발 → 시장·실행 자료 검토
- 무역·소싱 → 제품 샘플 및 검토 자료
- 공급망 → 현장 출고 자료 확인
- 파트너십 → 사업 조건 협의
- 해외시장조사 → 차트·자료 분석
- 수출 컨설팅 → 수출 관련 서류 검토
- 프랜차이즈 → 매장 현장 운영 협업
- 발매트 → 운전석 발매트, 타월 → 섬유 조직, 방향제 → 송풍구 액세서리, 필름 → 필름 샘플
- 트렁크 라이너 → 기존 후보 데이터 유지, 맞지 않는 사진으로 공개하지 않고 비공개

## 구조 및 유지보수
- 한국어/영어 메인을 정적 HTML로 빌드. 메인 본문은 JS 없이도 읽을 수 있음.
- 서비스·상품·이미지는 공개 Excel 기반. `이미지맵`으로 문구와 사진을 함께 검수 가능.
- 가격/무료 진단/간편 견적에 언어 선택 전달, 영어 옵션 문구 보완.
- 기존 Supabase schema·Auth·보고서 payload 및 백업 Secrets는 변경하지 않음.
- 이미지 로컬 경로/페이지 링크/사진 중복 매핑/메타데이터 자동 검증 추가.

## 이미지의 한계
이번 작업은 기존 대화에서 제공된 생성 이미지의 색·구도·크롭을 정리한 것입니다. 실제 촬영물로 교체되었다고 주장하지 않습니다. 완전한 실사로 확정하려면 승인된 실제 제품·사업현장 사진을 `이미지맵`의 해당 파일로 교체하면 됩니다.
