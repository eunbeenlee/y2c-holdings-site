# 이미지 배치표 · V20

기존 제공 이미지에서 업무나 제품을 식별할 수 있는 부분을 골라 색상·구도를 정리했습니다. 실제 사업현장·직원·납품실적 사진이 아닌 생성 연출 이미지이며, 원본 대형 파일은 이 배포 ZIP에 중복 포함하지 않습니다.

| 연결 키 | 배치 파일 | 표시 의미 |
|---|---|---|
| `hero` | `hero-operations.webp` | 출고장과 적재 화물로 표현한 해외 공급 실행 |
| `business-development` | `service-development.webp` | 사업 자료와 시장별 실행안을 검토하는 업무 장면 |
| `trade-sourcing` | `service-sourcing.webp` | 제품 샘플과 검토 자료를 비교하는 소싱 업무 장면 |
| `supply-chain` | `service-logistics.webp` | 창고에서 입출고 자료를 확인하는 공급망 관리 장면 |
| `strategic-partnerships` | `service-partnership.webp` | 서로 사업 조건을 협의하는 파트너 미팅 장면 |
| `overseas-sales` | `service-sales.webp` | 상품 자료와 화상회의를 활용한 해외영업 협의 장면 |
| `market-research` | `service-analysis.webp` | 시장별 차트와 조사 자료를 비교하는 분석 장면 |
| `buyer-development` | `service-buyer.webp` | 해외 거래 후보와 사업 조건을 논의하는 장면 |
| `export-consulting` | `service-export.webp` | 선적 서류와 확인 목록을 검토하는 수출 준비 장면 |
| `franchise-development` | `service-franchise-field.webp` | 매장 운영 담당자와 현장 업무를 검토하는 장면 |
| `AUTO-001` | `product-floor.webp` | 고정 부위와 표면 패턴이 보이는 운전석 발매트 연출 예시 |
| `AUTO-002` | `product-towel.webp` | 자동차 관리용 극세사 타월의 조직과 두께 연출 예시 |
| `AUTO-003` | `product-fragrance.webp` | 송풍구 장착형 차량용 방향제 연출 예시 |
| `AUTO-005` | `product-film.webp` | 투과 색상을 비교하는 차량용 필름 샘플 연출 예시 |

## 교체 원칙
사진 교체 시 Excel `이미지맵`의 같은 `key`를 사용합니다. 원본 로고는 `site/assets/y2c-logo.png`입니다. 사진의 대체 텍스트와 실제 내용이 일치하도록 한·영 설명을 함께 수정합니다.

방향제 이미지는 장착 예시가 아닌 제품 형태 설명용입니다. 제품 안전성·공급 사양·차량 호환성을 사진만으로 보증하지 않습니다.
