## 반드시 구분할 사항

브라우저는 환경 정책상 로컬 서버/외부 주소 이동을 차단했습니다. 대신 **실제 HTML·CSS·JS를 about:blank에 인라인 로드**하여 레이아웃과 입력 동작을 검사했습니다. 외부 사진은 명확히 표시된 테스트용 SVG, Supabase는 모의 클라이언트를 사용했습니다.

따라서 69개 화면 검사는 **최종 사진 표시·크롭·외부 이미지 다운로드·실제 HTTP 페이지 이동** 검증이 아닙니다. 테스트 스크린샷을 실사진 적용 완료 화면으로 제공하지 않습니다.

사진 빌드 경로의 격리 테스트는 크기·색이 지정된 합성 파일을 입력으로 사용했습니다. 이것은 다운로드를 제외한 코드 흐름의 테스트이며, 이 합성 파일과 결과 사진·영수증은 최종 소스에 포함하지 않았습니다.

## 원본 검토 범위

사진 원본 페이지·제공된 화면을 보고 피사체를 검토해 카테고리에 대응시켰습니다. 자동 테스트는 그 연결 ID·설명·경로가 모든 페이지에서 일치하는지 검사합니다. 사진 내용을 자동으로 법적·기술적으로 인증하는 기능이 아닙니다.

실내 매트는 소재 TPE 여부를 단정하지 않습니다. 차량 유리 사진은 필름 원단이나 시공 성능 증거가 아닙니다. 방향제 사진도 Y2C의 확정 공급품이 아닙니다.
