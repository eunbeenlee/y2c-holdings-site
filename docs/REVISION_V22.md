# V22 수정 기록 — 2026-11-03

## V21 실제 파일에서 발견한 문제

- 385px 폭의 항만 부분 이미지를 큰 메인 배너에 확대하는 구조.
- 생성 회의 이미지의 부분 크롭을 서로 다른 서비스 사진으로 사용하는 반복.
- 서비스명과 서류 사진의 의미가 구체적으로 구분되지 않음.
- 실제 상품의 재질·모델을 확인할 수 없는 사진에 TPE 등 단정적 명칭을 붙임.
- 산업 항목이 메인·무료 진단·간편 견적·관리자 입력에서 달랐음.

## 변경

- 생성 사진을 삭제하고 11개 고유 원본의 출처·용도·프레임을 명시.
- 사업영역 6개·소싱 품목 4개·산업 6개 분리. 서비스 카드는 메인·목록·상세 및 국영문이 하나의 사진 렌더 함수를 사용.
- 산업 선택지를 Excel의 같은 데이터로 공급. 기존 관리자 자유 입력은 보존하고 선택 제안만 추가.
- 발매트의 TPE 확정 표현 제거. 방향제는 사진에 보이는 병형 제품만 설명. 틴팅은 실제 필름 확인이 아닌 차량 유리 적용 환경으로 명확히 표시.
- 공급권·실제 사업장·직원으로 오인하지 않도록 사진 출처와 참고 범위 표시.
- 가격·진단·관리자 입력 화면에는 불필요한 장식 사진을 넣지 않음.
- 브랜드 로고와 골드·차콜·오프화이트 테마 유지. 과한 금색 필터·초상 위주 구성 제거.
- 사진 다운로드 실패 시 빌드 중단. 서로 다른 카테고리에 무관한 기본 사진을 넣는 대체 로직 없음.
- 전체 사진을 내려받은 GitHub 빌드에서 사진 포함 소스 ZIP도 생성.

## 유지

기존 Supabase 인증·역할 정책·보고서 데이터 형태·가격·무료/유료 진단·한영 페이지·백업/점검 코드. 기존 SQL을 다시 실행하지 않습니다.

## 한계

제작 환경에서 사진 원본 파일 다운로드는 차단됐습니다. 이 전달 ZIP은 사진 포함 배포물을 만드는 전체 소스이며 원본 사진 바이너리는 포함하지 않습니다. 실제 사진의 최종 크롭·배포·운영 DB·이메일은 운영 환경 확인이 필요합니다.
