## 검증 방법과 한계 — 중요

실제 소스 HTML/CSS/JS와 동봉 JSON을 Chromium에 주입한 **네트워크 없는 브라우저 검증**입니다. 외부 폰트 요청 대신 시스템 폰트 대체가 사용됐으며 CDN 장애나 실제 배포 URL에 대한 네트워크 테스트는 아닙니다.

관리자 검사는 모의 Supabase 응답을 사용했습니다. 실제 사용자 비밀번호로 로그인하거나 운영 DB의 보고서를 읽고 수정하지 않았습니다. 모의 데이터·모의 인증코드는 공개 사이트에 포함하지 않습니다. 실제 사이트의 관리자 인증은 기존 Supabase 클라이언트와 RLS 구조 그대로입니다.

GitHub 배포, 실제 이메일 수신, 자동 예약 실행, 실제 Supabase 계정 로그인/저장은 사용자 계정 연결 상태에서 별도로 확인해야 합니다. 이미지가 생성 연출물이라는 사실은 바뀌지 않으며, 실제 직원·고객사·납품 실적 자료로 사용하면 안 됩니다.

## 배포 후 확인

1. Actions에서 `Publish Y2C Excel Website`의 최신 실행 성공 확인.
2. 브라우저 강력 새로고침 후 메인 사진·영문 페이지·상품 필터 확인.
3. 회사 계정으로 관리자 로그인 → 테스트 보고서 저장 → 새로고침 후 재조회.
4. 무료 진단·선택형 견적·가격 계산 확인.
5. 백업/점검 Secrets가 기존대로 남아 있는지 확인하고 실제 실행 결과 확인.
